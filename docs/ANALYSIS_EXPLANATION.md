# 📖 분석 수식 및 차트 심층 해설

이 문서는 `analysis.py`/`fetch_kma_data.py`가 내부적으로 어떤 계산을 하는지, 각 차트가 무엇을 보여주는지 설명합니다.

## 1. 폭염·열대야 판정 기준

- **폭염(is_heatwave)**: 해당 일의 최고기온(`max_temp`) ≥ 33.0℃
- **열대야(is_tropical_night)**: 해당 일의 최저기온(`min_temp`) ≥ 25.0℃

기상청이 실제로 사용하는 공식 정의(폭염특보 기준 등)를 단순화한 값으로, `fetch_kma_data.py`에서 이 두 상수(`HEATWAVE_THRESHOLD`, `TROPICAL_NIGHT_THRESHOLD`)만 바꾸면 다른 기준으로 재계산할 수 있습니다.

## 2. 결측치 처리 — 선형보간(Linear Interpolation)

기온 관측값이 API 응답에서 비어 있는 경우, `df.interpolate(method="linear")`로 처리합니다. 이는 결측 지점 앞뒤의 실측값을 직선으로 이어 그 사이 값을 추정하는 방법입니다. 예를 들어 6/10일이 결측이고 6/9일이 24℃, 6/11일이 26℃라면 6/10일은 25℃로 채워집니다. 시계열 데이터에서 가장 단순하고 보수적인 결측 처리 방법입니다.

## 3. 9월 늦더위 전이 예측 모델 — "평년값 + 감쇄 편차"

`build_forecast()` 함수의 핵심 아이디어:

1. **평년값(Climatology)**: 과거 연도들의 같은 날짜(월-일) 평균기온을 구합니다. 예: 과거 5개년의 "9월 5일" 평균기온.
2. **올해 편차(Anomaly)**: 올해 실측 구간(6~8월)에서 "실측값 − 그날의 평년값"의 평균을 구합니다. 이 값이 양수면 올해가 평년보다 더웠다는 뜻입니다.
3. **감쇄(Decay)**: 예측 구간(9월)의 각 날짜에 이 편차를 그대로 더하지 않고, 시간이 지날수록 편차의 영향력을 선형으로 줄여서(`np.linspace(1.0, 0.2, n)`) 더합니다. 예측 첫날은 편차의 100%를, 예측 마지막 날은 20%만 반영합니다 — "여름의 기세가 시간이 지나며 약해진다"는 가정을 수식으로 표현한 것입니다.

`예측값 = 그날의 평년값 + (올해 편차 × 감쇄계수)`

이 모델은 **실제 수치예보가 아닌 통계적 baseline 추정**입니다. 태풍, 대기 정체 같은 단기 기상 현상은 반영하지 못하므로, 실제 9월이 지나면 `fetch_kma_data.py`를 다시 실행해 예측과 실측을 비교(사후 검증)해보는 것을 권장합니다.

## 4. 4대 핵심 시각화 차트 상세 해석

### 📊 차트 1: 연도별 폭염·열대야 발생 일수 비교 (`01_extreme_weather_by_year.png`)
- **빨간 막대(폭염 일수)**: 2021년 18일 → 2022년 10일(최저) → 2023년 19일 → **2024~2025년 27일(정점)** → 2026년 15일로 하락.
- **파란 막대(열대야 일수)**: 2021년 20일 → 2022년 20일 → 2023년 18일 → 2024년 35일 → **2025년 44일(정점)** → 2026년 22일로 하락.
- **해석**: "매년 꾸준히 증가"가 아니라 **2024년을 기점으로 계단식으로 뛰었다가 2026년에 다시 내려온** 패턴입니다. 2024~2025년이 6년 중 가장 더웠던 2년이었고, 2026년은 6년 중 두 번째로 온건한 해(가장 온건한 해는 2022년)입니다.

### 📈 차트 2: 올해 실측 기온 타임라인 + 9월 예측 (`02_timeline_and_forecast.png`)
- **실선(6/1~8/24 실측)**: 6월 1일 최고기온 28.7℃로 서늘하게 출발했다가, 6/16(33.2℃)·6/19(34.0℃)에 일시적으로 폭염 기준을 넘는 스파이크가 있었습니다. 7월은 폭염 기준을 넘긴 날이 단 2일(7/12 35.0℃, 7/13 33.5℃)뿐으로 뚜렷이 잠잠했습니다. 반면 **8월 1일~11일 사이 9일 동안 연속적으로 33~38℃대 고온이 이어져**(8/7 38.0℃로 6년 통틀어 공동 최고), 이 짧은 구간에 여름 폭염일수(15일)의 상당수가 몰렸습니다.
- **점선(예측 구간)**: 실측 마지막 날(8/24) 다음 날부터 점선으로 자연스럽게 이어지며, 9월 상순 평균 최고 약 29.3℃에서 하순 약 26.6℃로 완만히 하강합니다.
- **음영 구간**: 예측이 시작되는 정확한 날짜부터 표시되어, "어디까지가 실측이고 어디부터 예측인지"를 한눈에 구분할 수 있습니다.

### 🗺️ 차트 3: 월별 평년 대비 기온 편차 히트맵 (`03_monthly_anomaly_heatmap.png`)
- **2024년 8월(+2.06℃)과 9월(+1.97℃)**이 6년 중 가장 짙은 붉은색(이상고온) 구간입니다. 반대로 **2022년 8월(-1.53℃)**이 가장 짙은 파란색(이상저온) 구간입니다.
- **2026년**은 6월(+0.42℃)·8월(+0.45℃)은 옅은 붉은색, **7월(-0.58℃)은 옅은 파란색**으로 나타나 "고르게 더운 해"가 아니라 "월별로 엇갈린 해"임을 시각적으로 보여줍니다.
- 흥미로운 점은 **6월과 8월의 편차 크기(+0.42℃, +0.45℃)가 거의 같은데도, 폭염일수는 6월 2일 vs 8월 11일로 크게 차이 난다**는 것입니다. 이는 편차가 아니라 절대 기온이 임계값(33℃)을 넘느냐가 폭염 판정의 기준이기 때문입니다 — 8월의 평년 기온(27.27℃)이 이미 33℃에 훨씬 가까워, 같은 크기의 양의 편차라도 임계값을 넘기 훨씬 쉽습니다.
- 9월 컬럼은 2021~2025는 실측치, 2026만 예측치입니다.

### 🏃 차트 4: 연도별 누적 폭염일수 페이스 비교 (`04_cumulative_heatwave_pace.png`)
- 2024~2025년(진한 주황/빨강) 곡선은 여름 중반부터 가파르게 계단식으로 상승해 27일에 도달합니다.
- **2026년(굵은 실선)은 8월 초(8/1~8/11) 구간에서만 집중적으로 계단식 상승**하고 그 외 구간은 평평하게 이어지다 15일에서 멈춥니다. 이 시기의 최장 연속 폭염 스트릭은 8일로, 2023~2024년(각 12일)보다는 짧지만 2022년(5일)보다는 깁니다.
- 9월 예측 구간(점선)에서는 더 이상 오르지 않아 수평으로 이어집니다 — 예측 모델이 9월 폭염을 0일로 산출했기 때문입니다.

## 5. 핵심 개념 요약

| 개념 | 이 프로젝트에서의 의미 |
| :--- | :--- |
| 트렌드(Trend) | 여러 해에 걸친 장기적인 방향성 (예: 폭염일수가 계속 느는가) |
| 계절성(Seasonality) | 매년 6월에 시작해 8월에 정점, 9월에 하락하는 반복 패턴 |
| 편차(Anomaly) | "오늘 값 − 평년 평균값" — 절대값보다 이례성을 잘 보여줌 |
| 감쇄(Decay) | 예측에서 최근 관측의 영향력을 시간에 따라 점점 줄이는 기법 |
| 관찰(Fact) vs 해석(가설) | 관찰은 숫자로 확인되는 사실, 해석은 그에 대한 추정(틀릴 수 있음) |
